# LinkedIn Post Draft

Excited to share TerraSynapse, our ISRO BAH 2026 project on cross-modal satellite image retrieval.

We worked on retrieving semantically similar Earth-observation scenes across SAR, optical, and multispectral imagery. The core idea was to learn a shared embedding space where a query from one modality can retrieve relevant results from another.

What we built:

- SAR, optical, and multispectral retrieval workflows
- Same-modal and cross-modal evaluation pipelines
- Hybrid attention-based model experiments
- Retrieval metrics using F1@K, Recall@K, mAP@K, and query latency
- Final report, presentation, architecture diagrams, and retrieval visualizations

This project was a strong learning experience in remote sensing, representation learning, model evaluation, and building a research-style submission under real constraints.

Grateful for the opportunity to participate and collaborate with the team.
